## Non-AI infrastructure target
Prefer, in order:
1. existing contracted infrastructure;
2. free/always-free cloud tiers;
3. scale-to-zero/serverless;
4. one low-cost shared runtime;
5. paid capacity only after measured need.

A persistent CEREBRO Browser may require an always-on compute node if event monitoring must continue while no authorised edge device is online. Current market examples show small cloud VMs in the low-single-digit EUR/month range and always-free compute options exist, but suitability must be benchmarked for Chromium profiles, concurrent accounts, encryption and monitoring load.

Target operating envelope after V1:
- DeepSeek variable: 0-10 EUR/month total authorised envelope unless OWNER_ROOT changes it.
- Browser/runtime: fit inside the same target where technically possible; if a persistent browser demonstrably needs more, present measured RAM/CPU/session evidence and exact monthly delta before purchase.
- Mobile/PC/extension software: no recurring licence requirement by default.
- Voice: open/local models first; paid voice SaaS not required.
