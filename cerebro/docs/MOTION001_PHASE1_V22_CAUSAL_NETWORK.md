## Purpose

Advance Phase 1 from an attractive neural animation toward a causal visual presence where activity appears to move through coherent areas and between functional regions.

## Owner direction incorporated

V2.1 was accepted as a strong direction. The next requested quality jump is to make the network feel more organic, more volumetric and more intelligible: activity should arise in a local neural area, propagate through connected filaments, travel between regions and activate the next area instead of appearing as unrelated random sparks.

## V2.2 changes

1. Organic curved filaments
   - local connections use restrained quadratic curvature;
   - long-range inter-area routes use broader curvature;
   - no rigid straight-line web as the dominant visual language.

2. Causal cluster propagation
   - each MOTION state has a deterministic regional sequence;
   - a micro-area activates first;
   - local connected routes brighten;
   - an inter-area route carries the signal;
   - the destination cluster then activates.

3. Depth hierarchy
   - rear geometry is dimmer / less prominent;
   - foreground geometry is brighter and more legible;
   - this prepares the visual language for CEREBRO Inside and later true 3D.

4. Neuron hierarchy
   - primary hub nodes;
   - secondary nodes;
   - micro-nodes;
   - hub nodes become natural future anchors for engine-family / engine navigation.

5. Inter-area neural highways
   - restrained long-range bridges connect logical regions;
   - these bridges are visually secondary while latent;
   - they become prominent only when causal activity crosses regions.

6. Pulse geometry
   - travelling pulses follow the exact same curved filament geometry;
   - pulse, active filament and afterglow are spatially coherent.

## State behavior

- IDLE: low causal activity around CORE with occasional local propagation.
- LISTENING: receptive area → local region → CORE.
- PROCESSING: multi-stage propagation through several regions and return to CORE.
- SPEAKING: CORE → output-side region → outbound focal area.
- HUMAN_REQUIRED: CORE → one amber focal area; no full-brain recolor.
- DEGRADED: CORE-only / reduced activity and density.
- ERROR: CORE → localized red fault area; route does not imply system-wide failure.
