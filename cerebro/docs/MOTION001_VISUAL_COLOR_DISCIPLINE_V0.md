## Owner feedback

The multi-colour visual system is rejected as a default because it distracts, dirties the composition and weakens the premium CEREBRO identity.

## Canonical palette

Default visual language:
- background: near-black / very dark navy;
- structural particles and neural field: deep blue / electric blue;
- secondary energy: cyan;
- highlights / high-energy nodes: white;
- no rainbow engine coding;
- no per-engine permanent colour assignment by default.

## How different engines/states are distinguished instead of colour

Primary differentiation must use:
1. spatial region / cluster location;
2. intensity / brightness;
3. node density;
4. pulse rhythm;
5. route direction;
6. particle speed;
7. depth / focus;
8. camera attention / zoom;
9. labels in forensic / operator views only.

This keeps the avatar and the neural interior visually clean while still allowing precise operational reading.

## Exception colours

Accent colour is reserved for exceptional semantics, not decoration:
- HUMAN_REQUIRED: restrained amber/gold accent;
- ERROR / SECURITY_INCIDENT: restrained red accent;
- success/normal operation does not require green; remain inside blue/cyan/white language;
- no flashing colour changes; accessibility rules remain mandatory.

Accent colours must affect only the focal cluster/route/indicator, never recolour the entire brain.

## Engine atlas policy

The operator atlas may identify motors with labels, IDs and region boundaries, but the brain itself remains primarily monochrome blue/cyan/white. Engine identity is spatial and behavioral first, chromatic only as an optional inspection overlay.

## Visual hierarchy

- Presence / avatar view: almost entirely blue/cyan/white.
- Inside / exploration view: same palette, with activation shown by luminance and motion.
- Ops map: labels and subtle overlays permitted.
- Forensic/replay: temporary diagnostic accents permitted only when they communicate a real event or exception.

## Acceptance rule

Any new MOTION-001 concept that looks busier, more colourful or less legible than the approved neural-swarm seed fails the visual canon gate.

The target is premium, calm, technological and clean — not a multicolour dashboard.
