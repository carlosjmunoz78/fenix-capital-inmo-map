# CEREBRO OS · RSI · Continuity / Auto-Handoff V0

El handoff preventivo se genera desde estado vivo y exige cuatro artefactos: maestro DOCX, prompt exacto TXT, STATE JSON y README MD.
Debe incluir repo/branch/HEAD/PR/runs, archivos, bloques, next_block, errores/correcciones, decisiones, HUMAN_REQUIRED y live_verification_targets mínimos.
Mismo HEAD: reanudar directamente. HEAD distinto: verificar solo PR/HEAD/CI/diff desde handoff; nunca reinvestigar CEREBRO completo.
