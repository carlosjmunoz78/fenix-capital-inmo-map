# VOICE-001 · es-ES Accent Diagnostic V0

Status: `LAB_LISTENING_ONLY / NON_PROMOTIONAL`

Purpose: generate a longer default-voice sample to let the owner judge whether the backend drifts between Spain Spanish and Latin-American Spanish before any real CEREBRO voice slot is accepted.

The diagnostic intentionally includes Spain-Spanish cues: `vosotros`, names from Córdoba province, dates, money, mortgage vocabulary and words containing `z`, `c` before `e/i`, and common pronunciation stressors.

This diagnostic does **not** prove:
- that the default model voice is suitable for the CEREBRO bank;
- that an authorized reference voice will sound the same;
- that cloning similarity is acceptable;
- that any of the 20 slots is accepted;
- PREPROD or PROD readiness.

Acceptance remains physical human listening + measured QA. If the backend exhibits persistent accent drift, the next action is to compare an authorized Spain-Spanish reference and, if necessary, another zero-cost local backend under the same corpus.
