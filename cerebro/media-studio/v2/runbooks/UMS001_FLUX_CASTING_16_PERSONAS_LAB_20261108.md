# UMS-001 · Biblioteca de personajes españoles ficticios · FLUX 1.1 Pro · LAB

## Producción
Primera batería de 16 *cast cards* fotográficas originales, de personas españolas ficticias de distintas edades (24–70 años), apariencia, color y peinado. Parejas hombre-mujer, dos hombres, dos mujeres, hogares monoparentales, familias con hijos y personas solas; representación inclusiva sin estereotipos. Los perfiles se definen por necesidades inmobiliarias reales (primera compra, vivienda accesible, cambio de etapa, familia, reducción de tamaño, autónomos), **no se inferirán datos sensibles de clientes ni se utilizarán orientación sexual o discapacidad para publicidad segmentada**.

Las imágenes de referencia no constituyen personajes aprobados ni garantizan consistencia entre tomas. Una vez superada revisión de rostros/manos/realismo/marca, congelar mejores identidades, archivar original + seed + prompt + SHA-256, y usar FLUX Kontext Pro con la referencia aprobada para ampliar emociones/vestuario/escenas. Ninguna persona real sin cesión de derechos.
