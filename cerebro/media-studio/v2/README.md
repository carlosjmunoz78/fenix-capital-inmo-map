## Objective
Materialize the canonical Universal Media Studio V2 organization inside CEREBRO as an additive, isolated PROD namespace before connecting it to live execution.

The base organization is:
- 1 Studio Brain (`UMS-BRAIN-001`)
- 48 department heads
- 384 specialist roles
- 32 independent supervisors
- 12 tribunals / 48 independent judges
- 16 guardians
- unlimited ephemeral production pods
- total: 529 base logical roles

The number 529 is a baseline, not a ceiling. FACT-001 may create new logical roles when a capability-gap analysis proves that no existing role owns the required contract.

## Execution topology
`UMS-BRAIN-001 -> department head -> specialists/pods -> supervisor -> tribunal -> guardians -> release`

Roles are logical contracts, not 529 permanent servers or 529 paid-model processes. Runtime, queues, tools, models, storage, evidence and observability are shared where safe.

## Initial PROD bootstrap rule
This directory is additive and does not replace existing CEREBRO/App/CRM/SEO/WordPress behavior. Registry and contracts may live in `main` immediately; live media execution is enabled only after the corresponding capability has executable tests, observability, rollback and rights/policy checks.

## Mandatory identity / clone policy
CEREBRO must support professional identity reconstruction, digital doubles, authorized voice cloning, authorized video/person reconstruction, motion transfer, voice conversion, multilingual dubbing and persistent characters.

For a real person, execution requires a valid `identity_rights_record` describing consent/authorization, permitted modalities and uses, provenance, scope and revocation. Synthetic-original identities may be generated without such real-person consent because they do not represent a real individual.

No component may bypass third-party authentication, CAPTCHA/MFA, platform anti-abuse controls, legal restrictions, consent requirements, rights restrictions or security controls. When a source found on the Internet cannot be lawfully reused, CEREBRO may use it only as research/reference and must create an original or properly licensed alternative.

## Continuous improvement
Every role receives a Learning Inbox. Daily Media Technology Scout deduplicates those learning requests and evaluates new models, tools, papers, codecs, devices, workflows and techniques through:

`discover -> license/security/rights -> capability map -> gap/duplicate analysis -> benchmark -> quality/cost/latency/privacy -> OLD vs NEW -> tribunal -> promote/reject -> learning memory`
