## Execution topology
`UMS-BRAIN-001 -> department head -> specialists/pods -> supervisor -> tribunal -> guardians -> release`

Roles are logical contracts, not 529 permanent servers or paid-model processes. Runtime, queues, tools, models, storage, evidence and observability are shared where safe.

## Clone / identity capability target
The studio is explicitly structured for:
- persistent synthetic characters;
- authorized real-person face/body reconstruction;
- authorized digital doubles;
- authorized voice cloning and voice conversion;
- authorized singing voice;
- video -> persistent character reconstruction;
- motion/performance transfer;
- scene/camera/lighting reconstruction;
- multilingual ADR/dubbing and lip sync.

Real-person execution remains fail-closed unless the rights record contains valid authorization, provenance and revocation information. Internet discovery never creates reuse rights automatically.

## Effects / assets target
Effects are first-class assets, not hard-coded presets. Families include particles, fire/smoke, fluids, destruction, electricity/energy, atmosphere/weather, optical/lens/light, fantasy, sci-fi, impact, transitions, motion graphics, Foley, SFX, ambience, music stingers, creatures, crowds and custom effects. Effects can have generated/procedural/captured/licensed/internal origins, versions, parameters, rights and provenance.

## Continuous improvement
Every role has a Learning Inbox. Daily Media Technology Scout deduplicates requests and runs:

`discover -> license/security/rights -> capability mapping -> duplicate/gap analysis -> LAB benchmark -> quality/cost/latency/privacy -> OLD vs NEW -> tribunal -> promote/reject -> learning memory`

Knowledge horizons: `NOW`, `EMERGING`, `COMING`, `FRONTIER`.

## Readiness rule
`UNIVERSAL_MEDIA_STUDIO_READY` is **false** until all 12 mandatory physical benchmarks are `PASS_WITH_EVIDENCE`.

The required suite covers persistent character, authorized digital double, authorized voice clone/VC/TTS, original song with stems, full sound scene, 3D/VFX shot, volumetric/spatial asset, XR output, device/holographic adapter, long-form continuity, thousand-shot simulation, and rebuild/rollback/provenance/rights/delivery.
