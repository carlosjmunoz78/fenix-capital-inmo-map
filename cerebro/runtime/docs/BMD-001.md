# BMD-001 · Business Model Discovery V0.2

Estado: PREPROD determinista. Coste adicional 0 €. Runtime compartido.

BMD ensambla un perfil de negocio a partir de tres fuentes permitidas: identidad/geografías de `COMP-REG-001`, evidencia pública `SCAN-001` y hechos estructurados declarados. No usa IA para completar huecos y `inferred_claims` permanece vacío en V0.

Dimensiones: services, products, customer_segments, value_propositions, geographies, channels, objectives y restrictions. Registry aporta geografías; SCAN aporta el canal web y redes sociales observadas. Los claims sustantivos de negocio sólo aparecen si fueron declarados.

Si menos del 75 % de dimensiones quedan pobladas, devuelve `LOW_CONFIDENCE`; no lo convierte en una afirmación inventada. Cross-company y material secreto se deniegan.
