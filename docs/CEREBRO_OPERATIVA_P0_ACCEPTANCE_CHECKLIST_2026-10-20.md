# Acceptance checklist · CEREBRO OPERATIVA P0

## 1 · Voz completa desde la primera palabra
- [ ] Abrir OPERATIVA en candidate/PREPROD.
- [ ] Iniciar `Hablar`.
- [ ] Realizar al menos 3 respuestas consecutivas con frases que comiencen por palabras claramente identificables.
- [ ] Confirmar físicamente que se escucha la primera palabra completa en las 3 respuestas.
- [ ] Confirmar que sigue funcionando la vuelta automática a ESCUCHANDO.
- [ ] Confirmar pausa/continúa.

## 2 · Conversaciones
- [ ] Abrir pestaña lateral.
- [ ] Crear conversación A y conversación B.
- [ ] Ver título automático desde la primera intervención.
- [ ] Renombrar A manualmente.
- [ ] Cambiar A → B → A y confirmar que se recuperan los mensajes correctos.
- [ ] Refrescar página y confirmar persistencia local.
- [ ] Confirmar que una acción pendiente no pasa de un hilo a otro.
- [ ] Probar drawer en anchura móvil.

## 3 · Procesos
- [ ] Abrir un proceso completado OK.
- [ ] Ver propósito, inicio, finalización, duración, resultado, versión y evidencia.
- [ ] Abrir un proceso en curso y ver ahora/siguiente/ETA cuando exista evidencia.
- [ ] Abrir un proceso no OK si existe uno disponible.
- [ ] Ver `Qué ha pasado`, job y paso afectados cuando GitHub los publique.
- [ ] Si GitHub no publica causa, comprobar que la interfaz no inventa ninguna.

## Promoción
No promover de forma autónoma a PROD mientras queden casillas físicas críticas sin aceptar o exista un gate rojo.
